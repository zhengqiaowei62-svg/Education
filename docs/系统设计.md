# 系统设计

## 架构图

```mermaid
graph TD
    U[用户浏览器 SPA] -->|HTTP /api| GW[FastAPI Gateway]
    GW --> P[Parser 解析层]
    GW --> KGE[KG Extractor]
    GW --> KGA[KG Aligner]
    GW --> RAG[RAG Pipeline]
    P -->|Textbook JSON| ST[(本地存储)]
    KGE --> ST
    KGA --> ST
    RAG --> VDB[(ChromaDB)]
    KGE -.LLM.-> LLM[(LLM API)]
    KGA -.LLM+Embedding.-> LLM
    RAG -.Embedding+LLM.-> LLM
```

## 数据流（一次完整流程）

1. 用户在左栏拖拽教材 → `POST /api/upload`
2. 后端 `parser.parse` 输出 `Textbook`，写入 `_TEXTBOOKS`
3. 用户点"抽取" → `POST /api/graph/extract` 按章节并发 LLM 抽取 → 单本图谱
4. 用户点"融合" → `POST /api/graph/merge` 调用 `kg_aligner`：embedding 初筛 + LLM 二筛 → 决策列表 + 融合图谱
5. 用户点"建索引" → `POST /api/rag/index` 分块 + embedding 入 ChromaDB
6. 用户提问 → `POST /api/rag/query` 检索 top-5 → 注入 prompt → LLM 生成 + 引用回填

## 技术选型与理由

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 后端 | FastAPI | 异步原生、Pydantic 自动文档、单文件可起 |
| PDF | PyMuPDF | 速度快、能拿字号做章节启发 |
| 向量库 | ChromaDB | 嵌入式、零运维 |
| Embedding | BGE-small-zh / OpenAI | 中文优化 / 备选 |
| LLM | OpenAI 协议（DeepSeek/通义） | 工具链统一 |
| 前端 | Vue 3 + Vite | 启动快、SFC 简洁 |
| 可视化 | AntV G6 | 力导向 + 交互完善 |
| UI | TailwindCSS | 极速布局 |

## API 接口示例

### POST /api/upload - 教材上传
```bash
curl -X POST http://localhost:8000/api/upload \
  -F "files=@生理学.pdf" \
  -F "files=@神经生物学.md"
```
响应：
```json
{
  "uploaded": [
    {"textbook_id": "book_a1b2c3d4", "filename": "生理学.pdf", "chapters": 8, "total_chars": 45230},
    {"textbook_id": "book_e5f6g7h8", "filename": "神经生物学.md", "chapters": 5, "total_chars": 23100}
  ],
  "errors": []
}
```

### POST /api/graph/merge - 跨教材融合
```bash
curl -X POST http://localhost:8000/api/graph/merge \
  -H "Content-Type: application/json" \
  -d '{"textbook_ids": ["book_a1b2c3d4", "book_e5f6g7h8"], "similarity_threshold": 0.55}'
```
响应：
```json
{
  "nodes": 89,
  "edges": 134,
  "decisions": 23,
  "stats": {
    "node_count_before": 127,
    "node_count_after": 89,
    "compression_ratio": 0.70
  }
}
```

### POST /api/rag/query - RAG问答
```bash
curl -X POST http://localhost:8000/api/rag/query \
  -H "Content-Type: application/json" \
  -d '{"question": "什么是静息电位？", "top_k": 5, "search_mode": "hybrid"}'
```
响应：
```json
{
  "answer": "静息电位是指细胞在未受刺激时（静息状态下）膜内外的电位差...",
  "citations": [
    {
      "textbook": "生理学",
      "chapter": "第三章 细胞的基本功能",
      "page": 35,
      "relevance_score": 0.92,
      "quote": "静息电位（resting potential）是指细胞处于安静状态时..."
    }
  ]
}
```

### POST /api/chat - 统一聊天入口

```bash
  -d '{"message": "把抗原和免疫原分开", "history": []}'
```
响应：
```json
{
  "intent": "MODIFY",
  "answer": "已将「抗原」和「免疫原」拆分为独立节点",

```
