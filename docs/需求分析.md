# 需求分析

## 子问题分解

1. **知识点粒度定义**：以"可独立解释的概念/定理/方法/现象"为最小单元，章节内一般 5–20 个。
2. **重复判定标准**：embedding 余弦相似度 ≥ 0.85 进入候选；LLM 二次判定为 `equivalent` 才合并。
3. **教学连贯性保障**：合并时保留原前置依赖关系；删除前检查是否被其它节点 `prerequisite`。
4. **压缩比计算**：`merged_chars / Σoriginal_chars`，要求 ≤ 30%。
5. **RAG 分块策略**：滑动窗口 600 字 + 80 字 overlap，保留 (textbook, chapter, page) 元数据。
   - 选择理由：中文教材一段平均 200–400 字，600 字可包含 1–3 段完整论述；80 字 overlap 防止概念跨块切断。
